# Duoverse Downloads

Temporary Windows installer downloads for Duoverse testing.

## Download and install

1. Open [Releases](https://github.com/AlNoMansLand/duoverse-downloads/releases).
2. Open the latest release and expand **Assets**.
3. Download the `Duoverse_..._x64-setup.exe` installer and run it on your Windows PC.

If no release is listed, the installer has not been uploaded yet.
